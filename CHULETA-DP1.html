La clase ya trae su propio Integer id; (G3)

Borrar esa línea y poner extends BaseEntity. Si se dejan los dos, hay dos id y Spring no arranca. No usar @Id @GeneratedValue propio: la secuencia de BaseEntity empieza en 100 para no chocar con los ids del data.sql.

¿Cuándo @NotNull?

Caso ¿@NotNull?
El enunciado dice «obligatorio / no nulo / required» ✅
«Opcional» o no dice nada ❌
Relación con destino 1, 1..n, 2..n (mínimo ≥ 1) ✅ (+ @Size(min = N) si es lista)
Relación con destino 0..1, 0..n ❌
El id ❌ nunca
  • @Size no impide el null → obligatorio con tamaño = @NotNull @Size(...).
  • @NotBlank ya incluye el @NotNull.
  • En una lista: @NotNull rechaza null, @Size(min = 1) rechaza [] → hacen falta las dos (o @NotEmpty para mínimo 1).
  • Tipos primitivos (int, boolean) nunca son null: @NotNull no hace nada.

Checklist

Java
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;   // el de SPRING

@Service
public class XService {
    XRepository repo;

    @Autowired
    public XService(XRepository repo) { this.repo = repo; }

    @Transactional(readOnly = true)
    public List<X> getAll() { return (List<X>) repo.findAll(); }

    @Transactional(readOnly = true)
    public X getById(Integer id) {
        return repo.findById(id)
            .orElseThrow(() -> new ResourceNotFoundException("X", "id", id));
    }

    @Transactional(rollbackFor = MiExcepcion.class)        // si la excepción es checked
    public X save(X x) throws MiExcepcion {
        // 1º comprobar reglas → throw
        // 2º repo.save
        return repo.save(x);
    }
}
  • @Transactional en cada método, no en la clase.
  • Leer → readOnly = true. Escribir → sin readOnly.
  • Excepción extends Exception → rollbackFor. extends RuntimeException → no hace falta.
  • La regla se comprueba antes de repo.save (verify(repo, never()).save(...)).

Condiciones: escribir la condición válida y negarla:

(De Morgan: !(A || B) = !A && !B)

Comparar: - Ids → a.getId().equals(b.getId()) (nunca == con Integer). - Si el test crea objetos sin id → comparar objetos (==). - Nunca comparar un id con un objeto entero.

Java
import java.util.Comparator;

Esquema: lista.stream() → operaciones intermedias (filter, map, sorted...) → una operación final (toList, count, anyMatch...). ⚠️ Un stream no modifica la lista original: hay que hacer return o guardarlo en una variable.

Quiero… Stream Devuelve
Quedarme con los que cumplen algo .filter(x -> cond) stream
Transformar cada elemento .map(x -> otraCosa) stream
Ordenar ascendente .sorted(Comparator.comparing(X::getCampo)) stream
Ordenar descendente .sorted(Comparator.comparing(X::getCampo).reversed()) stream
Pasar a lista .toList() List<X> (no modificable)
¿Alguno cumple? .anyMatch(x -> cond) boolean
¿Todos cumplen? .allMatch(x -> cond) boolean
¿Ninguno cumple? .noneMatch(x -> cond) boolean
Contar .count() long
Sumar un campo .mapToInt(X::getCampo).sum() int
Máximo / mínimo .max(Comparator.comparing(X::getCampo)) Optional<X>
El primero que cumpla .filter(...).findFirst() Optional<X>
Quitar repetidos .distinct() stream
Agrupar por algo .collect(Collectors.groupingBy(X::getCampo)) Map<K, List<X>>

    public ChessMatchService(ChessMatchRepository repo) { this.repo = repo; }

    @Transactional(readOnly = true)
    public List<ChessMatch> findAll() { return repo.findAll(); }

    @Transactional(readOnly = true)
    public Optional<ChessMatch> findById(Integer id) { return repo.findById(id); }

    @Transactional(rollbackFor = InvalidWinnerException.class)
    public ChessMatch save(ChessMatch match) throws InvalidWinnerException {
        User winner = match.getWinner();
        boolean valid = winner == null || winner == match.getWhite() || winner == match.getBlack();
        if (!valid) {
            throw new InvalidWinnerException();      // antes de repo.save
        }
        return repo.save(match);
    }
}

@Transactional(rollbackFor = MalformedCommunityException.class)
public Community save(Community c) throws MalformedCommunityException {
    // Regla 1: cada miembro ha jugado al menos 2 partidas en las temporadas de la comunidad
    for (User u : c.getMembers()) {
        int played = 0;
        for (Season s : c.getSeasons()) {
            for (ChessMatch m : s.getMatches()) {
                if (m.getWhitePlayer().getId().equals(u.getId())
                 || m.getBlackPlayer().getId().equals(u.getId())) {
                    played++;
                }
            }
        }
        if (played < 2) throw new MalformedCommunityException("Member with fewer than 2 matches");
    }
    // Regla 2: "no superior al máximo" → error cuando es MAYOR
    if (c.getMembers().size() > c.getMaxPlayers()) {
        throw new MalformedCommunityException("Too many members");
    }
    return repo.save(c);
}
